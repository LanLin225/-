# 简介
这是一个本地离线网页粒子特效制作工具，在画布上渲染粒子场，内置可视化控制面板，支持实时调整粒子参数、预览效果，支持鼠标交互，可把调好的粒子配置导出，也能直接复制粒子代码嵌入其他网页作为动态背景。

## 客户端调用两种方案

### 方案 1：客户端模组（Fabric / Forge）读取网页导出 JSON

1. 在 particle-studio.html 调好粒子动画，导出粒子 JSON 配置文件。
2. 客户端 Mod 内置粒子渲染器，加载这份 JSON，在客户端本地执行粒子运动逻辑。
3. 服务端仅发送**触发指令 / 标记**（如：玩家释放技能），**粒子全部在本地生成**，服务端不推送每一颗粒子。

- 优势：高密度粒子、拖尾、湍流、复杂螺旋都能做，**完全不卡服务器 TPS**
- 缺点：仅安装这个 Mod 的玩家才能看见特效；需要开发客户端模组。

### 方案 2：水影（Waterfall）客户端组件、注入渲染（你当前 26.2 开发场景）

水影客户端可通过组件开发，读取网页导出的粒子参数，在客户端渲染层绘制粒子。

1. 网页编辑器调参，导出 JSON 粒子运动描述（生命周期、加速度、湍流、颜色曲线）。
2. 客户端组件加载 JSON，在`renderWorld`阶段，在玩家 / 实体坐标生成粒子。
3. 可做：屏幕空间粒子、世界空间粒子、准星特效、周身环绕粒子、爆炸闪光。

> 
> 重要区分：
> 
> 
> - 服务端插件粒子：所有玩家都能看到，消耗服务器带宽 + TPS
> - 水影客户端粒子：**仅当前玩家本地可见**，零服务器开销，适合 HUD 特效、个人专属视觉效果

### 客户端调用参数适配要点

1. 单位转换：网页像素单位 → MC 世界坐标（方块）；网页时间（ms） → MC tick（1tick=50ms）
2. 渲染层级：区分**世界空间粒子（在地图里）** 和**屏幕空间粒子（HUD，贴屏幕）**
3. 性能限制：客户端侧也不能无限制堆粒子，过多会造成玩家客户端掉帧。
4. 颜色：客户端渲染可支持完整 RGB，不受原版`dust`粒子限制，可以做平滑渐变、透明度变化。

## 客户端和服务端方案对比

表格

| 项目 | 服务端插件粒子 (MythicMobs 等) | 客户端本地粒子 (Mod / 水影组件) |
| --- | --- | --- |
| 可见范围 | 同世界所有玩家 | 仅本地玩家 |
| 服务器 TPS 开销 | 高，大量粒子会压垮 TPS | 几乎无开销 |
| 特效上限 | 受原版粒子类型限制 | 自定义形状、渐变、拖尾，上限极高 |
| 依赖 | 服务端插件，玩家原版客户端即可 | 需要对应客户端 Mod / 注入组件 |

## 客户端使用流程总结

1. 在 particle-studio.html 可视化调试粒子运动形态、颜色曲线、湍流。
2. 导出 JSON 粒子描述文件。
3. 客户端 Mod / 水影组件读取 JSON，解析粒子生成规则。
4. 服务端只简单发送触发信号（可选），客户端本地生成并渲染整套粒子动画。

## 功能概述

这是一个本地离线网页粒子特效制作工具，在画布上渲染粒子场，内置可视化控制面板，支持实时调整粒子参数、预览效果，支持鼠标交互，可把调好的粒子配置导出，也能直接复制粒子代码嵌入其他网页作为动态背景。

### 核心能力

1. **粒子渲染**：Canvas 绘制大量粒子，支持圆点、方块、三角等粒子形状；粒子具备大小、透明度、生命周期、运动速度、重力、湍流、拖尾效果。粒子间可开启连线，距离近的粒子自动生成连接线，经典星空连线效果。
2. **鼠标交互**：鼠标移入画布区域，粒子会被鼠标引力 / 斥力影响，实现推开、吸附、跟随效果；支持点击画布生成爆炸粒子。
3. **可视化参数面板**
   - 粒子数量、粒子大小范围
   - 粒子颜色、渐变、透明度
   - 运动参数：速度、方向、重力、风力、湍流扰动
   - 连线开关、连线最大距离、连线透明度
   - 鼠标交互强度、粒子拖尾长度
4. **画布适配**：自动跟随窗口大小变化，响应式渲染；支持清空画布、重置粒子配置。
5. **导出功能**：导出当前粒子 JSON 配置，或直接生成可嵌入网站的 HTML 片段，拿来当网站首页、登录页动态背景。

## 技术架构

- 渲染层：HTML5 Canvas，requestAnimationFrame 动画循环，高性能粒子更新计算
- UI：原生 HTML+CSS 控制面板，不依赖 jQuery 等重型框架，单文件打包，所有代码写在 particle-studio.html 内，直接本地打开即可运行
- 运行方式：本地双击文件，Chrome/Edge 浏览器打开；**不需要服务器**，离线可用。

## 适用场景

- 前端开发：快速调试网页粒子背景效果
- 可视化演示、个人主页、登录页面动态背景
- 学习 Canvas 粒子物理运动算法
