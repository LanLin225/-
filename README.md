## 网页粒子特效工具描述

## 基础信息

类型：**单文件 HTML 粒子特效编辑器**，基于 HTML5 Canvas + JavaScript 实现，无需后端，双击直接在浏览器打开运行，属于蓝林源码项目内的前端可视化工具。

## 功能概述

这是一个本地离线网页粒子特效制作工具，在画布上渲染粒子场，内置可视化控制面板，支持实时调整粒子参数、预览效果，支持鼠标交互，可把调好的粒子配置导出，也能直接复制粒子代码嵌入其他网页作为动态背景。

### 核心能力

1. **粒子渲染**：Canvas 绘制大量粒子，支持圆点、方块、三角等粒子形状；粒子具备大小、透明度、生命周期、运动速度、重力、湍流、拖尾效果。粒子间可开启连线，距离近的粒子自动生成连接线，经典星空连线效果。
2. **鼠标交互**：鼠标移入画布区域，粒子会被鼠标引力 / 斥力影响，实现推开、吸附、跟随效果；支持点击画布生成爆炸粒子。
3. **可视化参数面板**
   - 粒子数量、粒子大小范围
   - 粒子颜色、渐变、透明度
   - 运动参数：速度、方向、重力、风力、湍流扰动
   - 连线开关、连线最大距离、连线透明度
   - 鼠标交互强度、粒子拖尾长度
4. **画布适配**：自动跟随窗口大小变化，响应式渲染；支持清空画布、重置粒子配置。
5. **导出功能**：导出当前粒子 JSON 配置，或直接生成可嵌入网站的 HTML 片段，拿来当网站首页、登录页动态背景。

## 技术架构

- 渲染层：HTML5 Canvas，requestAnimationFrame 动画循环，高性能粒子更新计算
- UI：原生 HTML+CSS 控制面板，不依赖 jQuery 等重型框架，单文件打包，所有代码写在 particle-studio.html 内，直接本地打开即可运行
- 运行方式：本地双击文件，Chrome/Edge 浏览器打开；**不需要服务器**，离线可用。

## 适用场景

- 前端开发：快速调试网页粒子背景效果
- 可视化演示、个人主页、登录页面动态背景
- 学习 Canvas 粒子物理运动算法
